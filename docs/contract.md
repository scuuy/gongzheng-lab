# 工程契约 v1

单位：mm、N、MPa。全局 X 为长度、Y 为宽度、Z 为厚度。几何为带通孔和顶面凸台的简化实体；并非某一客户生产零件。

## 输入

- parameters.json：长度、宽度、厚度、凸台高度和可选孔位覆盖；只读取 JSON，不执行提交代码。
- part.step：单实体几何。
- mesh.msh：Gmsh 二阶四面体和具有 CLAMP/LOAD 物理分组的边界三角形。
- analysis.inp：C3D10、E=70000 MPa、ν=0.3、X=0 三方向固定；X=length 上按二次三角形一致节点载荷分配合力。
- result.json：节点数、最大位移、网格和求解输入 SHA256。
- report.json：交付报告中的最大位移。
- requirements.json：公开要求。外部候选验收时使用验收端独立保存的可信副本。

## 八项检查

| 检查 | 当前判据 |
|---|---|
| 参数源 / STEP | 实体有效，双向布尔差体积之和 < 0.001 mm³ |
| 装配 | Z=15 mm 包络内净空 ≥ 0.5 mm |
| 变型 | 宽度 24/32/40 mm 时，圆柱孔中心 Y=0.2W，误差 < 0.01 mm |
| 网格粗一致性 | 包络误差 < 0.01 mm，线性角点四面体体积近似差 < 4% |
| 工况 | 提交 CLOAD 合力为全局 [0,0,-100] N |
| 提交结果 | 提交 deck 重算最大位移误差 < 1e-6 mm，哈希一致；由提交 mesh 和可信规范重新生成的受支持 deck 与提交输入归一化一致 |
| 报告 | 从当前参数独立重建全链，最大位移与报告差 < 0.001 mm |
| 响应 | 独立重算最大位移 ≤ 0.25 mm |

全部通过才 `accept`。正常完成但存在未通过检查为 `reject`。工具缺失、文件无法读取、超时等不形成有效工程结论；Web 端记 `infra_error`，CLI 返回非零。

## 覆盖与未覆盖

参数变型集合公开，当前产品验收示例不含隐藏参考。三种宽度通过仅代表该有限集合；不能保证连续尺寸范围。mesh 检查不能排除相同包络体积但拓扑不同的反例。deck 比对限制在本适配器支持的卡片与语义；不提供通用求解器形式化证明。设计意图、额外制造要求及企业专业审签仍需工程师补充。

## 模型提案

`gongzheng.proposal.v1` 仅接收有限数值参数，不允许命令、文件路径、材料、载荷或规范替换。外部模型只负责提案；可信执行器负责重建；独立验收器再次运行。报告结论与提案理由分别保留。人工决定实际发布。
