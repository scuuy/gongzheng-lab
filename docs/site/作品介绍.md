工程验证与回归测试平台

## 01 · 项目与问题 · 工业智能体的交付需要跨文件验证

 CAD/CAE 智能体会同时生成参数源、几何、网格、求解输入、结果和报告。各文件都能打开，仍可能存在几何更新后沿用旧网格、名义尺寸正确但变型失败、工况方向错误、报告引用旧数值等问题。  工证 Lab 面向工业 Agent 开发者、工业软件研发与测试团队，把交付验收组织为可重复执行的工程检查。当前原型使用开源 CAD/CAE 工具链，以受限参数支架模型展示从模型提案到原生重算的完整流程。  与相邻方案的关系    已有能力  本项目关注的补充    CAD 几何检查  连接参数、STEP、变型与装配要求    CAE 求解成功  复核工况、输入来源与报告一致性    Agent 任务打分  保留可重放原生工件和逐项测量    这些能力并非全部首创。当前实现的价值在于将它们组织为面向智能体交付的公开契约与回归流程；尚无系统性竞品性能对比。

## 02 · 产品流程 · 模型提案与可信验收分开执行

   接收提案： 模型或工程师提交有限参数 JSON，不执行模型生成的代码。   重建原生工程： 可信适配器生成 STEP、Gmsh 网格和 CalculiX 求解输入。   独立验收： 重新打开几何、检查有限参数变型、核验工况、重算原生结果并比对报告。   保存证据： 输出逐项判据、观测值、文件哈希和原生日志，工程师审查后决定是否发布。    实际产品截图，上半屏裁切。页面区分“已保存证据”和“本次独立运行”；演示修复按钮明确标注为确定性配方。

## 03 · 工程契约 · 八项检查覆盖当前受支持的工程路径

   检查  判据摘要    参数 / STEP  实体有效，双向差体积 < 0.001 mm³    装配净空  15 mm 包络内 ≥ 0.5 mm    参数变型  W=24/32/40 mm；孔位 Y=0.2W    网格粗一致性  包络差 < 0.01 mm；体积近似差 < 4%    载荷语义  全局 [0,0,−100] N    输入与结果  受支持 deck 与网格工况匹配；提交输入重算    报告复核  独立全链重算与报告差 < 0.001 mm    位移限值  独立计算 ≤ 0.25 mm    全部通过为 accept；正常完成但检查不通过为 reject；缺文件、工具失败、超时等不形成有效工程结论。外部智能体验收必须把可信要求单独保存，通过 --requirements 指定。  毫米、牛顿、兆帕；线弹性材料 E=70000 MPa、ν=0.3；X=0 固定，X=长度端按二次三角面一致节点载荷分配合力。当前不是任意 CAD/CAE 模型验收器。

## 06 · 架构与开源 · 可运行代码与第三方许可一起交付

 核心为 Python 验收器与受限适配器，界面使用 HTML/CSS/JavaScript。工具链：CadQuery 2.8.0 / OCP 7.9.3.1.1、Gmsh 4.12.1、CalculiX 2.21、meshio 5.3.5、NumPy 2.5.4。  Web 端每次原生运行使用独立工具容器，关闭网络、根文件系统只读、代码只读、单次输出目录可写；限制 2 CPU / 4 GB 内存 / 128 进程 / 600 秒时限。服务绑定 localhost，最多两项原生运行并行。  开源治理  自有代码与合成示例 Apache-2.0。原生工具保留 GPL/LGPL 等各自许可；当前分发源码和构建配方，不分发预构建二进制镜像。保留第三方说明、安全边界、贡献指南与路线图。  贡献路径：公开最小工程与授权来源 → 正例、负例、临界例、等价例 → 原生回归 → 维护者审查。新项目尚无外部贡献者和企业合作记录。  docker build -t gongzheng-native:0.1.0 .

## 07 · 发展与边界 · 以可复现反例推动工业验证能力扩展

 首批用户与计划  优先服务工业 Agent 研发与工业软件测试团队，提供版本变更后的工程回归。后续计划加入第二类几何、网格拓扑与边界质量、方向量纲契约，再探索 CI 批量运行、插件规范与团队审签服务。未宣称营收、真实客户部署或降本比例。  明确的覆盖边界   仅一个受限参数支架适配器与有限公开变型集合。  网格包络/体积是粗检查，不能证明任意网格几何等价。  求解输入归一化比对限制于受支持适配器，不是通用 INP 解释器。  未覆盖接触、塑性、疲劳和完整网格收敛；不构成生产安全认证。  无公网认证、任意上传或完整多租户隔离。   参赛交付与来源  代码仓库、作品介绍、路演、操作视频、原生回归与模型接入证据，见随附提交导航和清单。负责人身份与联系方式以正式报名表填写为准。  比赛规则来源：https://www.oschina.net/os2026/ 及官方公开 tracks/criteria/schedule/config 接口；2026-10-14 保存快照。AI＋工业软件评分：创新30%、落地30%、开源治理20%、长期发展20%。本说明不代替官方最终通知。
