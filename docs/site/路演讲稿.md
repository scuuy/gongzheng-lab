# 工证 Lab · 约五分钟讲稿

## 1. 工证 Lab

大家好，介绍工证 Lab。我们做的是 CAD 和 CAE 智能体交付的工程验证与回归测试。当前原型把参数源、原生几何、网格、求解输入和报告放到同一份可重放的验收记录中。

## 2. 工业 Agent 交付中的跨文件失配

工业智能体会生成多种文件，风险也会跨文件传播。一个典型例子是把载荷从负一百牛变成正一百牛，线弹性模型的最大位移模长仍可能一致。因此，求解成功和一个看起来合理的数字不足以判断工况正确。

## 3. 从模型提案到工程师放行的验证流程

工作流分成四个责任环节。模型只提交有限的参数提案；执行器重建原生工程；验收器根据独立要求重新打开和求解；最后由工程师结合检查覆盖决定是否放行。验收要求不交给候选修改。

## 4. 参数变型失效的原生验收

这个案例在二十四毫米宽度上看起来正常。缺陷是孔位被写成四点八毫米常数，宽度变成三十二和四十毫米后，要求分别是六点四和八毫米，原生圆柱面的测量暴露了失效。

## 5. 六组可重放案例的回归结果

我们构造一个正常对照和五种有明确工程意义的缺陷。六组结果与设计预期一致，逐个保留原生重算文件。这里不报告总体检出率，也不声称这些是高难模型评测。

## 6. 两次真实模型提案的接入结果

为了确认 AI 接口真实可用，我们通过现有网关调用 gpt-6-astra，分别生成两份参数提案，再由工具链重建和独立验收。两例均为八项通过。模型名称是网关返回标识，底层身份未独立认证，费用未知。

## 7. 开源 CAD/CAE 工具链与隔离执行

工具链基于 CadQuery、Gmsh 和 CalculiX。Web 端单次任务在关闭网络的容器内执行，保留 STEP、网格、求解输入、原生结果和日志。网格一致性当前是包络和体积粗检查，能力边界在文档中明确列出。

## 8. 开源治理与可复现交付

开源交付包括代码、输入契约、回归测试、贡献指南和第三方许可说明。我们计划优先吸收可复现的工程反例，而不是只收集成功截图。当前是新项目，没有虚构社区规模或企业合作。

## 9. 首批用户与后续扩展计划

最先服务的是开发工业 Agent 的研发和测试团队。先把一种受限几何模型和公开工况的接口做扎实，再增加适配器和批量回归，后续探索团队部署服务。这些属于路线图，尚未验证商业收益。

## 10. 当前覆盖范围与参赛交付

当前原型可以运行、重算和审查，材料中也明确列出尚未覆盖的边界。希望让工业智能体每一次工程修改都能留下可检查、可重放的证据。谢谢。
