# 现场演示手册

## 提前准备

从提交包 code/ 或仓库根目录执行：

```sh
docker build -t gongzheng-native:0.1.0 .
scripts/docker-run.sh regression
python3 -m gongzheng.cli serve --port 8770
```

提前构建镜像、完成回归，确认 Docker 可用且至少 4 GB 内存。打开 http://127.0.0.1:8770 。本次交付本地 Linux ARM64 原生链已实测；其他环境先做预演。首次构建需要网络，原生验收容器禁用网络。

## 三至五分钟操作

1. 正常交付：展示参数、STEP、网格、求解输入、结果之间的关系和八项通过记录。
2. 选择“默认正确、变型失效”，点击“启动独立验收”；说明本次启动新的工具容器。
3. 展开孔位关系：24/32/40 mm 三种宽度，固定孔位只满足第一种；展示实际量测与要求。
4. 查看模型接入实测中的 variant 提案，说明是保存的真实模型结果；点击“重放此模型提案”。
5. 等待重新生成工程和独立复验，检查八项通过，并下载候选 STEP/INP。不要把确定性配方按钮说成 AI。
6. 选择“求解完成、载荷反向”，启动独立验收，说明为何位移模长相同也不能通过。
7. 总结适用范围、证据链和下一阶段真实试点计划。

## 现场故障处理

容器启动失败、超时或工具错误显示 infra_error，不作工程 reject。保留 runs/<job>/process.log 排查；不要把失败伪装成通过。网络不稳定时用本地 MP4 作为已录制演示，并明确说明；本地页面不会实时调用模型 API。

材料门户是静态展示；真正的工程计算在本地产品服务完成。现场不要将 localhost 服务直接暴露到公网。
