# 操作视频说明

视频为中文产品的实际浏览器操作录屏，保留原生计算等待；使用 macOS 系统中文合成旁白及烧录字幕。未用动画替代求解结果。全部工程为项目自行生成的合成示例。

模型提案来自两次真实网关调用。视频中的“重放此模型提案”应用保存的 JSON 后重新生成工程并独立验收，不在录制时再次请求模型。另一个“按演示配方修复”按钮为确定性流程。

章节：正常交付与工件链 → 参数变型验收 → 孔位失效证据 → 保存的模型提案 → 重放与复验 → 载荷方向检查 → 能力边界。

最终 MP4 采用 H.264 / AAC，附独立 SRT；字幕按旁白段落估时，不宣称逐字强制对齐。原始录屏、任务结果和媒体探针记录保存在制作证据中。
